Store Intelligence Platform
1.1 Problem Statement
Apex Retail operates 40 physical stores across 8 cities. Their online channel tracks every session, click, and drop-off in real time. Their offline stores are a complete data blind spot. Store managers have no reliable data on:
How many unique customers enter each day and how many make a purchase
Which product zones attract attention but fail to convert
How deep billing queues get and how many customers abandon before purchase
Whether their conversion rate today is better or worse than last week
This creates a $X revenue opportunity gap: decisions about store layout, staffing, and promotions are made on gut feel rather than data.

1.3 Core Features ΓÇö Must Have (Hackathon Scope)
Part A ΓÇö Detection Pipeline
Person detection from CCTV footage using YOLOv8 + ByteTrack
Handle groups entering simultaneously ΓÇö count individuals, not groups
Staff detection and exclusion from customer metrics (uniform-based or VLM)
Re-entry detection ΓÇö same physical person returning after EXIT must produce REENTRY event
Partial occlusion handling ΓÇö degrade gracefully, emit with low confidence, never drop
Structured event emission matching exact schema
8 event types: ENTRY, EXIT, ZONE_ENTER, ZONE_EXIT, ZONE_DWELL, BILLING_QUEUE_JOIN, BILLING_QUEUE_ABANDON, REENTRY
Per-session visitor_id token via Re-ID (bounding box trajectory + OSNet/torchreid)
ISO-8601 UTC timestamps derived from clip start + frame offset
Cross-camera deduplication ΓÇö same person across overlapping camera FOVs counted once
POS transaction correlation ΓÇö billing zone presence in 5-min window before transaction = conversion
Part B ΓÇö Intelligence API (FastAPI)
POST /events/ingest ΓÇö batch ingest up to 500 events, idempotent by event_id
GET /stores/{id}/metrics ΓÇö unique visitors, conversion rate, avg dwell per zone, queue depth, abandonment rate
GET /stores/{id}/funnel ΓÇö Entry ΓåÆ Zone Visit ΓåÆ Billing Queue ΓåÆ Purchase with drop-off %
GET /stores/{id}/heatmap ΓÇö zone visit frequency + avg dwell, normalised 0ΓÇô100
GET /stores/{id}/anomalies ΓÇö queue spike, conversion drop, dead zone alerts with severity + suggested_action
GET /health ΓÇö service status, last event per store, STALE_FEED if >10 min lag

docker compose up ΓÇö zero manual steps beyond git clone

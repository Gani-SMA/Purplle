=== TABLE 10 ===
Why YOLOv8x: Best trade-off of accuracy vs speed for 1080p/15fps retail footage. YOLOv8x outperforms YOLOv8n/s/m on crowded-scene benchmarks. RT-DETR considered but requires more GPU memory. ByteTrack chosen over DeepSORT ΓÇö no appearance model required at tracking stage, faster, and appearance Re-ID handled separately by OSNet.

=== TABLE 18 ===
Step | What Happens
Step 1 ΓÇö Load | run.sh reads clip paths from config. FFmpeg decodes to frames. store_layout.json loaded for zone polygons.
Step 2 ΓÇö Detect | YOLOv8x runs on each frame (class 0 = person only, conf ΓëÑ0.45). Returns bounding boxes per frame.
Step 3 ΓÇö Track | ByteTrack assigns track_id across frames. Handles occlusion, ID-switch.
Step 4 ΓÇö Re-ID | OSNet extracts 512-dim embedding per tracklet. Cosine similarity check against exit pool for REENTRY.
Step 5 ΓÇö Staff | HSV colour range check on clothing region. If ambiguous ΓåÆ optional Claude Vision API call.
Step 6 ΓÇö Zone | Centroid of bbox checked against zone polygon definitions from store_layout.json. Zone ID assigned.
Step 7 ΓÇö Events | State machine per visitor_id emits typed events: ENTRY ΓåÆ ZONE_ENTER ΓåÆ ZONE_DWELL ΓåÆ ZONE_EXIT ΓåÆ BILLING_QUEUE_JOIN ΓåÆ EXIT.
Step 8 ΓÇö POS Corr. | pos_transactions.csv correlated: visitor in BILLING zone within 5-min window before tx timestamp ΓåÆ is_converted=true.
Step 9 ΓÇö Emit | emit.py writes validated events to events.jsonl. Schema validated via Pydantic. Malformed events logged but not suppressed.

=== TABLE 24 ===
Edge Case | System Behaviour
Empty store (0 visitors) | API returns metrics with all zeros, no null fields, no 5xx
All-staff clip | is_staff=true on all events ΓåÆ conversion_rate=0, unique_visitors=0, no crash
Zero purchases | POS table empty ΓåÆ conversion_rate=0.0, abandonment_rate computed correctly
Re-entry in funnel | visitor_id counted once in unique visitors regardless of REENTRY event count
Duplicate POST /ingest | Redis dedup by event_id ΓåÆ second call returns same accepted count, no double-persist
DB unavailable | FastAPI dependency check fails ΓåÆ 503 {error: 'database_unavailable', retry_after: 30}
Feed stale >10 min | /health shows STALE_FEED: true for that store_id
Low confidence event | Emitted with confidence value intact, NOT suppressed or elevated
Camera FOV overlap | Cross-cam dedup: Redis set of (visitor_id + store_id) with 5s TTL
Group entry (3 people) | 3 separate track_ids ΓåÆ 3 separate visitor_ids ΓåÆ 3 ENTRY events

=== TABLE 40 ===
